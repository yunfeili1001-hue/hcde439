Blink!

Three LEDs, one repeating sequence, and a first exploration of digital output with an Arduino Uno.

Project overview

Three colors.
One at a time.

I built a circuit with red, green, and blue LEDs connected to digital pins 9, 10, and 11. The Arduino turns on each LED for one second while keeping the other two off, then repeats the sequence.

Plan

Schematic & calculations

The red and green LEDs have an approximate forward-voltage drop of 1.8 V, while the blue LED has an approximate forward-voltage drop of 3.3 V. The target current from the course slide is 20 mA.

Red R = (5 − 1.8) / 0.020 = 160 Ω

Green R = (5 − 1.8) / 0.020 = 160 Ω

Blue R = (5 − 3.3) / 0.020 = 85 Ω

I used a 200 Ω resistor for each LED because that was the available value. The resulting current is approximately 16 mA for the red and green LEDs and 8.5 mA for the blue LED, which keeps the LEDs below the 20 mA target.

02

Build

Physical circuit

Digital pins D9, D10, and D11 each connect to one resistor and one LED. The other side of every LED connects to the Arduino ground, creating three separately controlled branches.

  • D9200 Ω → red LED → GND
  • D10200 Ω → green LED → GND
  • D11200 Ω → blue LED → GND

03

Test

Circuit operation

Only one LED is on at a time. The sequence begins with red, moves to green, then moves to blue. Each state lasts for one second before the loop starts again.

  1. 0–1 sRed LED on
  2. 1–2 sGreen LED on
  3. 2–3 sBlue LED on

Firmware

The code

Each output line has a short comment above it, and the three pins are controlled independently inside the repeating loop.

// Assign digital pin 9 to LED 1.
#define PIN_LED1 9

// Assign digital pin 10 to LED 2.
#define PIN_LED2 10

// Assign digital pin 11 to LED 3.
#define PIN_LED3 11

// Configure the Arduino pins when the program starts.
void setup() {
  // Set the LED 1 pin as an output.
  pinMode(PIN_LED1, OUTPUT);

  // Set the LED 2 pin as an output.
  pinMode(PIN_LED2, OUTPUT);

  // Set the LED 3 pin as an output.
  pinMode(PIN_LED3, OUTPUT);
}

// Repeat the blinking pattern continuously.
void loop() {
  // Turn on LED 1.
  digitalWrite(PIN_LED1, HIGH);
  // Turn off LED 2.
  digitalWrite(PIN_LED2, LOW);
  // Turn off LED 3.
  digitalWrite(PIN_LED3, LOW);
  // Keep this state for one second.
  delay(1000);

  // Turn off LED 1.
  digitalWrite(PIN_LED1, LOW);
  // Turn on LED 2.
  digitalWrite(PIN_LED2, HIGH);
  // Turn off LED 3.
  digitalWrite(PIN_LED3, LOW);
  // Keep this state for one second.
  delay(1000);

  // Turn off LED 1.
  digitalWrite(PIN_LED1, LOW);
  // Turn off LED 2.
  digitalWrite(PIN_LED2, LOW);
  // Turn on LED 3.
  digitalWrite(PIN_LED3, HIGH);
  // Keep this state for one second.
  delay(1000);
}

Reflection

Questions

01

Voltage across the LEDs over time

The red and green LEDs have an approximate voltage drop of 1.8 V, while the blue LED has an approximate voltage drop of 3.3 V. When an LED is off, the voltage across it is approximately 0 V. The three-second pattern repeats continuously.

02

How many LEDs could you blink independently? How much current would that draw?

The Arduino Uno has 14 digital I/O pins, so theoretically I could control 14 LEDs independently using one pin for each LED. If every LED drew 20 mA and all 14 were on at the same time, the total current would be 14 × 20 mA = 280 mA. This exceeds the microcontroller's 200 mA total current limit, so it would not be safe without reducing the current or using an external LED driver. In my current circuit, only one LED is on at a time, so the maximum LED current is approximately 16 mA.

03

How fast do the LEDs need to blink before they appear continuously lit?

At approximately 50 Hz, using 10 ms on and 10 ms off, the LED appears continuously lit and the blinking is no longer clearly visible. The exact threshold can vary depending on the observer, LED brightness, and lighting conditions.
