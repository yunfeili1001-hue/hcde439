01

Plan

Schematic & resistor calculations

Each LED has an independent series resistor and shares Arduino GND. Using the course estimate of 1.8 V forward voltage for both red and green, a 20 mA design current gives R = (5 − 1.8) / 0.020 = 160 Ω. Selecting 220 Ω reduces the estimated full-on current to (5 − 1.8) / 220 ≈ 14.5 mA per LED.

For the divider, V-measure = 5 × R-sensor / (10,000 + R-sensor). When the sensor is 10 kΩ, the measured voltage is 2.50 V and the ADC reading is about 512. A 10 kΩ fixed resistor matches the assumed thermistor resistance at 25°C, giving a centered reading and useful sensitivity near that temperature. With the assumed Beta model, 130°F gives R ≈ 3.040 kΩ and V ≈ 1.166 V; 140°F gives R ≈ 2.486 kΩ and V ≈ 0.996 V. These are calculated values, not measured voltages.

The fixed resistor limits divider current even if the sensor resistance approaches zero: I ≤ 5 / 10,000 = 0.5 mA. Maximum fixed-resistor power is 5² / 10,000 = 2.5 mW.

Physical circuit

  • D9220 Ω → green LED → GND
  • D10220 Ω → red LED → GND
  • Divider5 V → 10 kΩ → V-measure (A2) → thermistor → GND

V-measure is the junction between the two resistances. A separate wire connects this point to Arduino A2. As an NTC thermistor warms, its resistance decreases, so the voltage at A2 decreases with this wiring. All ground symbols refer to the same Arduino ground.

Test

Circuit operation

At every calculated temperature below 140°F, green D9 is on and red D10 is off. At or above 140°F, red D10 is on and green D9 is off. Brightness changes within 120–140°F for green and 140–160°F for red; these ranges affect brightness only. Below 120°F, green remains on at full brightness; above 160°F, red remains on at full brightness.

Firmware

A2 reads the divider; D9 controls green and D10 controls red. The switching threshold is 140°F. Each code line is explained below.

ADC readings range from 0–1023 and PWM from 0–255. Updates occur every 500 ms. The temperature calculation assumes a 10 kΩ thermistor at 25°C and Beta = 3950 K.

// Include the logarithm function used in the thermistor equation.
#include <math.h>

// Connect the green LED through 220 ohms to PWM pin 9.
const int GREEN_PIN = 9;
// Connect the red LED through 220 ohms to PWM pin 10.
const int RED_PIN = 10;
// Read the divider midpoint at analog input A2.
const int SENSOR_PIN = A2;
// Use a 10 kiloohm fixed resistor above the thermistor.
const float FIXED_R = 10000.0;
// Assume the thermistor is 10 kiloohms at 25 degrees Celsius.
const float NOMINAL_R = 10000.0;
// Express the nominal temperature in kelvin: 25 + 273.15.
const float NOMINAL_T = 298.15;
// Assume Beta is 3950 K; check this against the actual sensor specifications.
const float BETA = 3950.0;
// Switch from green to red at a calculated temperature of 140 degrees Fahrenheit.
const float THRESHOLD_F = 140.0;

// Configure the LED outputs and serial communication once.
void setup() {
  // Set the green LED pin to output mode.
  pinMode(GREEN_PIN, OUTPUT);
  // Set the red LED pin to output mode.
  pinMode(RED_PIN, OUTPUT);
  // Start the Serial Monitor connection at 9600 baud.
  Serial.begin(9600);
}

// Continuously read the sensor and update the indicator.
void loop() {
  // Read the 10-bit ADC value from A2, ranging from 0 to 1023.
  int raw = analogRead(SENSOR_PIN);

  // Reject endpoint readings to avoid division by zero or an invalid logarithm.
  if (raw <= 0 || raw >= 1023) {
    // Turn off the green LED for an invalid reading.
    analogWrite(GREEN_PIN, 0);
    // Turn off the red LED for an invalid reading.
    analogWrite(RED_PIN, 0);
    // Report the invalid reading instead of a temperature.
    Serial.println("Sensor reading invalid: check wiring.");
    // Wait half a second before checking again.
    delay(500);
    // Skip the remainder of this loop pass.
    return;
  }

  // Solve the divider equation for the thermistor connected below the midpoint.
  float resistance = FIXED_R * raw / (1023.0 - raw);
  // Apply the Beta equation to calculate inverse temperature in kelvin.
  float inverseT = (1.0 / NOMINAL_T) + log(resistance / NOMINAL_R) / BETA;
  // Convert the calculated kelvin temperature to degrees Celsius.
  float tempC = (1.0 / inverseT) - 273.15;
  // Convert Celsius to Fahrenheit for the threshold comparison.
  float tempF = tempC * 9.0 / 5.0 + 32.0;

  // Use the green indicator below the 140-degree Fahrenheit threshold.
  if (tempF < THRESHOLD_F) {
    // Limit only the green brightness calculation to 120–140 degrees; all values below 140 still select green.
    long boundedTemp = constrain((long)tempF, 120L, 140L);
    // Map 120–140 degrees to green PWM 255–60; colder readings stay at 255.
    int brightness = map(boundedTemp, 120, 140, 255, 60);
    // Set the active green LED brightness with 8-bit PWM.
    analogWrite(GREEN_PIN, brightness);
    // Turn off the red LED while green is active.
    analogWrite(RED_PIN, 0);
  }
  // Use red when the calculated temperature reaches or exceeds 140 degrees.
  else {
    // Limit the red brightness calculation to 140–160 degrees.
    long boundedTemp = constrain((long)tempF, 140L, 160L);
    // Map 140–160 degrees to red PWM 60–255; hotter readings stay at 255.
    int brightness = map(boundedTemp, 140, 160, 60, 255);
    // Set the active red LED brightness with 8-bit PWM.
    analogWrite(RED_PIN, brightness);
    // Turn off the green LED while red is active.
    analogWrite(GREEN_PIN, 0);
  }

  // Label the raw ADC reading.
  Serial.print("ADC: ");
  // Print the sensor reading from A2.
  Serial.print(raw);
  // Label the calculated temperature.
  Serial.print(" | Temperature: ");
  // Print Fahrenheit with one decimal place.
  Serial.print(tempF, 1);
  // Print the temperature unit and indicator label.
  Serial.print(" F | Indicator: ");
  // Print the current indicator color and end the line.
  Serial.println(tempF < THRESHOLD_F ? "GREEN" : "RED");
  // Update the output and serial log every 500 milliseconds.
  delay(500);
}

04

Explain

Additional questions

01 · Divider position

Can the variable resistor be R1 or R2?

Either position works: V-measure = 5 × R2 / (R1 + R2). With a 10 kΩ fixed resistor and a 5 kΩ thermistor, placing the thermistor at R2 gives 5 × 5 / 15 = 1.67 V; placing it at R1 gives 5 × 10 / 15 = 3.33 V. Swapping positions reverses the voltage response, so the code must match the wiring.

02 · Voltage over time

What happens at V-measure?

A2 voltage decreases as the NTC thermistor warms. Time is in seconds and voltage in volts. Measured values can be calculated from a serial log using V = ADC × 5 / 1023.

03 · Resolution

What changes with 10-bit PWM and a 16-bit ADC?

The original ranges are ADC 0–1023 and PWM 0–255: map(raw, 0, 1023, 0, 255). A 16-bit ADC and 10-bit PWM change this to map(raw, 0, 65535, 0, 1023), providing finer steps. The hardware must support these resolutions. If mapping temperature instead of raw ADC, keep the temperature endpoints and update the PWM endpoints.
